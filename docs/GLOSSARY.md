# Glossary

The terms the code and these docs use, in alphabetical order. A word with several meanings has one row per meaning, qualified in brackets; [Preferred words](#preferred-words) names the word prose should use for each. Code identifiers keep their names: the recommendations apply to documentation, comments and commit messages.

| Term                  | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Where                                                                                                                |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Adaptive step         | A governor tier change, or the resolution step, queued so it lands at a commit point: on the next tour cut once its programs have linked, at once while the tour is not running, and after 30 s at most.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | [runtime.js](../src/scene/runtime.js) `createDeferredQualityStep`                                                    |
| Angle                 | A shot within a view. `?angle=` and `sceneDebug.cinematic.angle` count from 1; `scene.cinematicAngle` and `cinematic.angle` count from 0.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | [cinematic.js](../src/scene/cinematic.js) `chooseCinematicAngle`                                                     |
| Asset tier            | The tier the models and slate maps were loaded for: the startup tier, kept for the visit, so an adaptive step never downloads another size.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | [index.js](../src/scene/index.js) `assetTier`                                                                        |
| Babel                 | The project's legacy namespace: `window.BabelSite`, the `babel:` User Timing names, `<meta name="babel:scene-script">`, the `__BABEL_*__` defines, names such as `BabelVignetteGrainShader`, and the build's `babel-build-` staging folders. It has nothing to do with the Babel compiler: esbuild builds the site and there is no Babel dependency.                                                                                                                                                                                                                                                                                                                                                                                               | [Contracts](CONTRACTS.md)                                                                                            |
| Baseline              | The scene without the film: the treatment every subsystem starts in and returns to with `setFilmTreatment(false)`, including the baseline hill ring, the non-film sky, lighting and grade, and `sceneDebug.groundTreatment: "baseline"`. Never revealed: the reveal waits for the watch, whose commit turns the film on.                                                                                                                                                                                                                                                                                                                                                                                                                           | [film-scene.js](../src/scene/film-scene.js), [hill-silhouette.js](../src/scene/hill-silhouette.js)                   |
| Bend weight           | `bend`, the cloud reshaping's weight on the noise's coordinates (horizon decompression, `CLOUD_RESHAPE.scale` and the swirl). Like the open weight it is exactly 0 over the reference banks and scaled by `uCloudReshape`, but it eases in over azimuths at least as wide and from a smaller radius (`CLOUD_RESHAPE.bend`), so the coordinates never bend fast enough to shear the noise, and it is not held off by the roof's clear lane, which keeps its own clearing in the density.                                                                                                                                                                                                                                                            | estate-sky.js `cloudFieldGLSL`                                                                                       |
| Bloom                 | The glow pass, on the high tier only, sized in CSS pixels.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | [postprocess.js](../src/scene/postprocess.js), [quality.js](../src/scene/quality.js) `postprocessBloom`              |
| Borrowed resource     | A geometry, material or program owned by one subsystem and replaced or extended by another, which restores the original before freeing its own.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | [Architecture](ARCHITECTURE.md#scene-lifecycle)                                                                      |
| Cadence               | Rendering on every nth vsync near 60 Hz. The divisor rounds down (144 Hz draws 72 fps), or up when the primary pointer is coarse, `(pointer: coarse)` (90 Hz draws 45); a touchscreen laptop with a fine pointer rounds down.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | runtime.js `renderDivisor`, index.js `displayCadence`, quality.js `touchPrimary`                                     |
| Capture (environment) | The one prefiltered (PMREM) cube of the film sky, taken when the film starts and again only after a lost context; the scene's environment map. It keeps the clouds as authored: the cloud reshaping is off in it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | [night-environment.js](../src/scene/night-environment.js), `sceneDebug.environment`                                  |
| Capture (review)      | A screenshot taken for review by the capture recipe.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | [Scene modes](SCENE-MODES.md#capture-recipe), [Testing](TESTING.md#visual-review)                                    |
| Capture (tour)        | The frame that stores the outgoing shot as the kept frame, one frame before the cut.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | [camera-tour.js](../src/scene/camera-tour.js) `transition.capture`                                                   |
| Brush (dissolve)      | The directional paint wash used only where both tour frames classify a pixel and its nearest neighbors as bare sky. Non-sky layers use continuous dissolves with the same stagger and soft boundaries.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | postprocess.js `DISSOLVE_BRUSH`, `DISSOLVE_SOFT`                                                                     |
| Brush (sky)           | The painted sky's brush (`CLOUD_BRUSH`): dry-brush strokes at the banks' edges and faint bristle streaks inside them, laid in the clouds' own noise space so they follow the flow; with `SKY_INK`'s brush-weighted ink.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | [estate-sky.js](../src/scene/estate-sky.js), postprocess.js `SKY_INK`                                                |
| Cel band              | The grade's posterising step: luma rounded to fifths, mixed in at `celMix` (0.24). In film only the sky takes it, the clouds' painterly steps; the subjects, mountains and ground shade continuously.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | postprocess.js, quality.js `postprocessSettings.celMix`                                                              |
| Cliffs                | Where the land ends at the fault: a shelf sharing the ground's complete material up to a crisp break (bare rock near it, `COAST_BEDROCK`), then a rock face about 13 units down to the sea and on under it, casting the moon's shadow with the stacks. Three ribs of broken rock jutting below the clifftop, and sparse rubble, share the face's existing geometry groups.                                                                                                                                                                                                                                                                                                                                                                         | [ocean.js](../src/scene/ocean.js) `createCliff()`                                                                    |
| Cloud field           | The film's cloud banks on the sky shell, as GLSL statements from the drift clock to the bank cover. The sky shell draws them, and the stars evaluate them where their view rays leave the shell, so they hide behind the banks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | [estate-sky.js](../src/scene/estate-sky.js) `cloudFieldGLSL`                                                         |
| Cloud reshaping       | The change that gives the sky outside the reference banks broad, swirling, layered banks like theirs. It works through two weights, the open weight on the bank density and the bend weight on the noise's coordinates, both exactly 0 over the reference banks. Through the bend weight come horizon decompression, an even enlargement of the noise (`CLOUD_RESHAPE.scale`) and a swirl driven by a half-frequency octave; through the open weight the same octave decides bank or clear sky, with darker lanes from the next octave inside the banks. The density lift leaves the roof's clear lane alone, and behind the name and intro the text guard takes density off the banks. Off in the environment capture.                            | estate-sky.js `CLOUD_RESHAPE`, `uCloudReshape`                                                                       |
| Coast albedo          | The optional 512px sRGB rock colour tile (77,902 bytes), normalized by its measured linear RGB mean. One independently owned texture supplies cliff faces, stacks and near-coast shelf bedrock on both live tiers; it loads after reveal and binds only at a cut or on a still frame, with procedural fallback.                                                                                                                                                                                                                                                                                                                                                                                                                                    | coast-detail.js `COAST_ALBEDO`, ocean.js, terrain-build.js                                                           |
| Coast detail          | The optional 256px packed data map: RG OpenGL normal X/Y, B roughness, `NoColorSpace`, shared by both live tiers on a 6.56-unit tile by the cliff faces, stacks and near-coast shelf bedrock (lent to the ground with the albedo, `coastRockUniforms`). Its independent lazy owner requests after reveal and binds only at a cut or on a still frame; failed detail leaves colour and procedural shading usable.                                                                                                                                                                                                                                                                                                                                   | [coast-detail.js](../src/scene/coast-detail.js), [Assets](ASSETS.md#coast-detail)                                    |
| Commit point          | A moment when a change can land without a visible pop: before the reveal, inside the fade-in, on a tour cut under the kept frame, or on any frame while the tour is not running.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | [Architecture](ARCHITECTURE.md#scene-lifecycle), terrain-build.js `unseen()`, runtime.js `createDeferredQualityStep` |
| Compact (composition) | The composition profile for viewports under 1100 px wide that match neither the phone nor the portrait-tablet profile. Not the compact variant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | quality.js `SCENE_COMPOSITION_PROFILES.compact`                                                                      |
| Compact (variant)     | A shot's framing on landscape canvases up to 500 px tall, at least 1.55:1 and under 600 px wide (568×320): The watch's drifts a little nearer the star's bearing than its landscape variant, so the star's glow stays off the intro.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | [directed-shots.js](../src/scene/directed-shots.js) `compact`                                                        |
| Composition profile   | The camera preset and world offset chosen from the viewport (`compact`, `desktop`, `portraitPhone`, `landscapePhone`, `tabletPortrait`): it frames the orbit camera, sets the camera's base field of view on resize and lowers the environment root by `sceneOffsetY`. The directed shots frame by the safe area and their variants instead.                                                                                                                                                                                                                                                                                                                                                                                                       | quality.js `SCENE_COMPOSITION_PROFILES`, `sceneDebug.composition`                                                    |
| Contact               | The footer's control: a button that shows and hides the email address and LinkedIn beside it (above it on phones), and that an address ending `#about`, `#profile`, `#experience` or `#contact` (or a `-text` form) opens. Without JavaScript it stays hidden and the two links stand alone in its place.                                                                                                                                                                                                                                                                                                                                                                                                                                          | [index.html](../index.html), [contact.js](../src/ui/contact.js)                                                      |
| Contacts              | Darkening of the slate about the tree's roots, the lantern and the rocks: `(x, z, radius, strength)` uniforms, so rocks arriving never recompile the ground.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | [mud-ground.js](../src/scene/mud-ground.js) `createSlateContacts`                                                    |
| Cut                   | The frame on which the tour switches to the next shot, under the kept frame.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | camera-tour.js `transition.cut`                                                                                      |
| Depth layer           | The film's code for a surface in the scene target's alpha: sky 0, mountains 1/3, ground 2/3, subject 1. The dissolve and the grade read it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | [depth-layers.js](../src/scene/depth-layers.js) `DEPTH_LAYER`                                                        |
| Discovery files       | `public/site-agents.md` (published as `/AGENTS.md`), `public/llms.txt`, `public/sitemap.md` and `public/index.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | [build.mjs](../build.mjs), [AGENTS.md](../AGENTS.md) rule 4                                                          |
| Dissolve              | The tour's crossfade from the kept frame into the live shot over 1 s (or 30% of a shorter dwell), staggered by depth layer: sky, mountains, ground, subject. It never passes through black.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | camera-tour.js `TOUR_TRANSITION`, postprocess.js `LAYER_STAGGER`                                                     |
| Drift                 | The camera's sweep across a shot's `arc` (degrees of azimuth): at a constant rate through a tour dwell, or a 48 s swing without a tour. Reduced motion holds it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | cinematic.js `apply`, [directed-shots.js](../src/scene/directed-shots.js) `arc`                                      |
| Dwell                 | How long the tour stays on a shot, cut to cut: 9, 7 or 6 s by shot, or a fixed 3, 5 or 20 s with `?tour=`. The code calls it `hold`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | directed-shots.js `hold`, camera-tour.js `TOUR_HOLD_FALLBACK`                                                        |
| Early request         | main.js's low-priority request for the startup tier's tree, made beside the scene bundle and shared on `BabelSite.scene.prefetched`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | [main.js](../src/main.js), [Contracts](CONTRACTS.md#windowbabelsite)                                                 |
| Estate layout         | The 3D world's anchors: the watch's terrace, the tree, the lantern and the winding path. Scene files named `estate-*` belong to the 3D world.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | [estate-layout.js](../src/scene/estate-layout.js) `ESTATE`                                                           |
| Fade-in               | The canvas's single 480 ms opacity transition when `#home-scene` gains `is-ready`. Under reduced motion the transition is `none`, so there is no fade-in.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | [styles.css](../styles.css) `.scene-canvas`                                                                          |
| Fallback (no-JS)      | The footer's email and LinkedIn links standing alone where Contact would be: the page without JavaScript, or before [contact.js](../src/ui/contact.js) binds.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | index.html `#contact-links`, contact.js                                                                              |
| Fallback (status)     | An asset, map or build that failed: `status: "fallback"`. A fallback watch or tree stops the scene for the title card; the lantern, slate maps, rocks and ranges keep what was there.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | [architecture-assets.js](../src/scene/architecture-assets.js), [Scene modes](SCENE-MODES.md#scenedebug)              |
| Falls                 | Where the river pours off the cliffs into the sea, north-east of the tree: its last run over the shelf and the sunken lip to its brink (the river's rapids), a falling white curtain along the cliff, and white water where it lands (`FALLS`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | [ocean.js](../src/scene/ocean.js) `riverFalls()`, `createFalls()`                                                    |
| Far plain air         | What the band under the ranges, below eye level and past the film terrain's edge, reads as: distant dark air (north-east, past the fault, the sea instead). That band is the ranges' lower bodies, which eases into the terrain's slate (`TERRAIN_HORIZON`) lifted 1.65× at eye level and rising to 1.9× where the view meets the terrain's edge (`TERRAIN_EDGE`); the mountain feet haze to the same air, and the slate's far edge darkens toward 1.75× the slate, never lightening. The ranges meet it through a rocky skirt (`HORIZON_SKIRT`).                                                                                                                                                                                                  | [hill-silhouette.js](../src/scene/hill-silhouette.js) `HORIZON_AIR`, mud-ground.js                                   |
| Fault                 | The line north-east of the estate, about 120 units out, where the land broke away (the owner's pick of 2026-10-17): broken into headlands, bays and V-shaped fractures, with its signed distance (positive inland) in JavaScript and GLSL from one table (`COAST`, `coastDistance()`, `seaCoast()`). Past it lie the cliffs and the sea; the ranges past its mean line sink.                                                                                                                                                                                                                                                                                                                                                                       | [ocean.js](../src/scene/ocean.js), hill-silhouette.js `SEA_SINK`                                                     |
| Fault's shots         | The broken coast, The falls and Over the fault (ocean.js `COAST_SHOTS`, the owner's picks of 2026-10-17): tour shots of the coast itself, not a subject, which join the tree's list when the sea lands and leave with it; each frames itself (`coastShot()`: its aim and lens set in the estate's frame) and keeps the film's shadow on the land (`shadow`).                                                                                                                                                                                                                                                                                                                                                                                       | [Scene modes](SCENE-MODES.md#shots), [Style](STYLE.md#sea-and-shore)                                                 |
| Film look             | The photographic finish in film (`FILM_LOOK`): warm-light halation and the print toe in the grade, midtone-weighted grain in the final pass, and gate weave as a subpixel camera-projection offset.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | [postprocess.js](../src/scene/postprocess.js)                                                                        |
| Film                  | The production look, turned on when the watch commits: a painted sky above continuously shaded physical subjects, ground, water and ranges, with the existing photographic finish and environment capture. A revealed scene is always in film.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | film-scene.js, index.js `onWatchReady`                                                                               |
| Fill (cool)           | The unshadowed cool directional light that keeps the subjects readable against the sky.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | [rendering.js](../src/scene/rendering.js) `lights.fill`, [world.js](../src/scene/world.js) `FILL_LIGHT_POSITION`     |
| Fill (crown)          | The tree's unshadowed point light (`tree-fill-light`), placed in the crown at (-3.8, 0.42 × `treeHeight`, -2.5) in the tree assembly's `root`, which the source's comment puts about 10 units above the lantern. It models the bark; in film it turns cool (`0xc2d2ec`) and its reach drops to 24.                                                                                                                                                                                                                                                                                                                                                                                                                                                 | [architecture.js](../src/scene/architecture.js) `TREE_FILL_INTENSITY`                                                |
| Fingerprint           | A published name `name.HASH.ext`, where `HASH` is eight hex digits of the file's SHA-256; immutable for a year.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | build.mjs, `public/_headers`                                                                                         |
| First frame           | The first frame the scene draws, on the hidden canvas, at or before the reveal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `babel:first-frame` ([Contracts](CONTRACTS.md#user-timing))                                                          |
| Gate (live)           | The asset controller requests models only from the scene's first frame update.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | index.js, architecture-assets.js `setQuality`                                                                        |
| Gate (static)         | A check in main.js that keeps the title card: forced colours, reduced motion, reduced data, no WebGL, a software renderer, or a low startup tier.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | main.js `ensureSceneReady`                                                                                           |
| Governor              | The adaptive quality controller: after the reveal it samples display intervals and steps the tier down under sustained load, and back up once the display keeps up. `?quality=high` or `balanced` pins it (no adaptive steps); `auto` leaves it free, and `low` never reaches the scene.                                                                                                                                                                                                                                                                                                                                                                                                                                                           | quality.js `createSceneQualityGovernor`                                                                              |
| Governor tier         | The governor's current tier. Its `low` is the resolution step, never the low tier.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `sceneDebug.governorTier`                                                                                            |
| Grade                 | The colour pass on both live tiers: continuous contrast, cool shadows, warm highlights and a soft highlight shoulder. Only the sky takes cel bands and ink. A separate continuous shadow toe preserves deep subject and mountain shade independently of cel strength.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | postprocess.js, quality.js `postprocessSettings`                                                                     |
| Grain (scene)         | The final vignette-grain pass's noise, fixed to a 1280×720 grid over the canvas and on both tiers (`postprocessGrain`); 0.008 strength in film. Not the title card's grain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | postprocess.js `BabelVignetteGrainShader`                                                                            |
| Grain (title card)    | A faint anti-banding grain over the title card's night: a 150 px inline SVG tile of white and black specks that balance on the night. It fades with the canvas's reveal (a sibling selector, so the vignette must follow the scene host), is absent under forced colours and increased contrast, and stays on the 404.                                                                                                                                                                                                                                                                                                                                                                                                                             | [styles.css](../styles.css) `.scene-vignette::before`                                                                |
| Hold (render)         | Rendering stops: the scheduler's `"visitor"` hold, from the reveal, while a visitor pause lasts. Behind it a resize, context restore or content change draws one still frame.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | runtime.js `createVisitorHold`                                                                                       |
| Hold (sampling)       | The 3 s after a resize, resume, context restore, pause release or asset commit during which the governor takes no samples.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | quality.js `SAMPLE_HOLD_MS`, `holdSampling()`                                                                        |
| Hold (shot)           | The code's name for a dwell.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | directed-shots.js `hold`                                                                                             |
| Hold (tour)           | The tour stops advancing on its current shot: reduced motion, a visitor pause or the walk. It resumes without a time jump.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | camera-tour.js                                                                                                       |
| Horizon band          | The film sky's faint lift at the horizon (`filmBand`); the ranges read it too, through `FILM_SKY_GLSL`, for the sky behind them. Not the far plain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | estate-sky.js `FILM_SKY_GLSL`                                                                                        |
| Horizon decompression | The cloud reshaping's first term: past a knee on the cloud plane the noise's radius grows more slowly than the plane's, so banks near the horizon keep about the reference banks' size instead of shrinking, with the plane's perspective, into small ovals. Below 15° of altitude the dome takes over (`CLOUD_RESHAPE.dome`; the reference banks' low part below 4°, `wedgeDome`), so they also keep their shapes instead of flattening into strips.                                                                                                                                                                                                                                                                                              | estate-sky.js `CLOUD_RESHAPE.horizon`                                                                                |
| Ink contour           | The grade's edge darkening from the luma difference between the samples one CSS pixel either side of each pixel, across and down (`uTexelSize` is one CSS pixel); in film only where a pixel and its four neighbours are all sky (the clouds' own edges).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | postprocess.js `uInkMix`, `uTexelSize`                                                                               |
| Kept frame            | The outgoing shot's graded frame, stored at the tour capture and dissolved into the live shot; it keeps pushing in by `zoom`. Changes that would pop land under it on a cut.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | postprocess.js, camera-tour.js                                                                                       |
| Knee                  | A soft highlight limit, `c / (1 + luma(c) / knee)`: a reflection or glint approaches a ceiling instead of clipping. The moon's glint uses 0.06, the lantern's 0.35, and reflections behind text 0.035, blended in across the text guard's reach (`slateTextKnee`): scaled into the divisor, a knee that low cuts a hard edge into bright glare. Beside the footer the lantern's pool on the soil passes 0.08 in shots that ask (`poolAbout`, `SLATE_LIGHT.poolKnee`).                                                                                                                                                                                                                                                                              | mud-ground.js `SLATE_WATER`                                                                                          |
| Lazy chunk            | A scene chunk loaded by dynamic `import()`: `architecture-prepare`, `terrain-build`, `mountain-build`, `rock-build`, `lantern-flame` and `walk`. Outside the 831 KiB scene budget.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | build.mjs, [Architecture](ARCHITECTURE.md#module-map)                                                                |
| Lease                 | A hold on a decoded model's textures, geometries and images through staging, commit and restoration; aborted and stale results release through the same path, and the resources are freed with the last lease.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | architecture-assets.js `retain()`                                                                                    |
| Live path             | A visit on which main.js requests the scene: every static gate passed and the startup tier is high, balanced or unknown.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | main.js                                                                                                              |
| Loading line          | The "Loading · N%" progress line above the footer, with a 2px bar along the window's top edge that fills to the same value, both in the name's colour, on the live path only, with its star. It completes at the reveal or retires below 100%.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | [scene-loader.js](../src/ui/scene-loader.js), `#scene-loader`                                                        |
| Loading line's star   | The scene's star drawn in CSS where the opening shot will show it, beneath the canvas, from the moment the scene reports where (the opening outline's fit, then the scene's own camera): an unseen ember that warms with the loading line's progress and, at the reveal, is the scene's star in place and size, as the canvas fades in over it. It goes with the line, and forced colours and increased contrast hide it.                                                                                                                                                                                                                                                                                                                          | scene-loader.js, `#scene-star`, [opening-star.js](../src/scene/opening-star.js), [UI](UI.md#loading-lines-star)      |
| Low tier              | The static tier: the title card only. main.js never requests the scene bundle for it, and the scene declines it when main.js could not tell.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | quality.js `selectSceneQualityTier`                                                                                  |
| Massifs               | Three real Alpine massifs from public elevation data (ridge: the Grandes Jorasses, spine: the Dents du Midi, summit: the Weisshorn), copied around the camera inside their culled viewing envelopes. Each GLB supplies sRGB albedo, an object-space normal map and an occlusion/snow data map (R AO, G snow), consumed by the existing continuous massif shader.                                                                                                                                                                                                                                                                                                                                                                                   | [mountain-build.js](../src/scene/mountain-build.js) `RANGE_PLACEMENTS`, hill-silhouette.js `MASSIFS`                 |
| Moon key              | The scene's directional key light and its only shadow caster, placed at `directionalPosition` (32, 28, 14) in index.js's `lightingConfig`; the environment capture centres its moon glow on that direction (`keyDirection`), and mud-ground.js `MOON_LIGHTS.key` restates it (a test holds them equal). The code names it `sunLight` (`rendering.lights.sun`); it is not the visible star, and it does not read world.js `SUN_DIRECTION`.                                                                                                                                                                                                                                                                                                          | rendering.js, index.js `lightingConfig.directionalPosition`, mud-ground.js `MOON_LIGHTS`                             |
